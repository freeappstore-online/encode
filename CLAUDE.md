# Encode

A free developer encoder/decoder toolkit on FreeAppStore.

- Subdomain: `encode.freeappstore.online`
- Dev: `pnpm install && pnpm dev`
- Build: `pnpm build`
- Deploy: `git push origin main` (auto-deploys via the FAS host Worker)

Tools included: Base64, URL, HTML entities, JWT decoder, hash (MD5/SHA-1/SHA-256/SHA-384/SHA-512), UUID v4, timestamp converter, color (HEX/RGB/HSL/HSV), unit converter, lorem ipsum.

Free, MIT-licensed, no tracking. For platform conventions, read
https://raw.githubusercontent.com/freeappstore-online/freeappstore/main/SKILLS.md
before writing or changing anything.
